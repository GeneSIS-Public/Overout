Overout v1.0.0 is the first official Release Package produced through `Operation: Protocol-Overout` and was publicly released on 2026-09-11.

### Added

SALVAGE: Clipboard Text Salvaging, ACTIVE / PASSIVE Acquisition, Layer Markers, alternating Tags, optional Timestamps, Undo Last Capture, L.A.I.N Navi, s-CO2, File Output, and Clear.

PREPARATION: direct editing of the Shared Document Buffer, standard Copy / Cut / Paste, P.R.E.S.S., C.O.D.E.C., I.C. Move, Blank / Layer Detection, Word Search, Structural Intervention, Blank Compress, and Right-click Edit.

ACTIVE and PASSIVE both perform Salvaging. SALVAGE and PREPARATION use the same Shared Document Buffer.

### Distribution

The official binary channel is the GeneSIS Official BOOTH. GitHub provides Public Documentation and verification information. Project: Code-NOAH Phase 1 Founder Support purchasers receive the same Release Build as an Additional Deliverable. No Founder-only binary is created. Source code is not public.
