# Overout v1.0.0 — Third-Party Software Notices

[English](./THIRD_PARTY_NOTICES_EN.md)

- **Document Version:** 1.0
- **Product:** `Overout v1.0.0`
- **Platform:** `Windows x64`

Overout v1.0.0の`Overout.exe`には、Applicationの実行に必要なThird-Party Runtime Componentsが含まれます。

通常利用のために、利用者がPython / pip / PyInstallerを別途Installする必要はありません。

本書はGitHub上でThird-Party Software情報への入口を提供するSummary / Navigation Documentです。完全なLicense / Notice Corpusは正式Release Package内に収録されています。

## 4. Relationship to the Overout EULA

Third-Party Componentsは、それぞれのLicense条件に従います。

Overout EULAはThird-Party Licenseを置き換えたり、その権利・義務を変更するものではありません。

## 5. Source Code

Overout Source Codeは公開していません。

Third-Party ComponentのSource Code提供・取得に関する権利が各Licenseにより認められる場合、その取扱いは当該Third-Party Licenseに従います。
