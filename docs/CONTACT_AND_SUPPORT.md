## 2. GitHub Issues

通常不具合では、可能な範囲で次を含めてください。

- Overout Version
- Windows Version
- 関係するFunction / Mode
- 問題概要
- 再現手順
- Expected / Actual
- Frequency
- 確認済みWorkaround
- 公開可能なLog / Screenshot

Public Issueへ次を投稿しないでください。

- 個人情報
- 購入情報 / BOOTH注文番号
- Founder確認情報
- Password、Token、API Key、秘密鍵、認証Code
- 機密Clipboard Text
- 第三者の秘密情報
- 非公開Local File
- 未修正Security問題の悪用可能な詳細

## 3. Private Inquiries

推奨Subject Prefix：

```text
[Purchase]   購入
[Founder]    Founder Support
[EULA]       EULA
[Rights]     権利・利用条件
[Privacy]    個人情報・Privacy
[Private Bug] 非公開不具合
[Other]      その他
```

Founder / 購入確認では必要に応じて、BOOTH注文番号、Product名、概算購入日等を確認する場合があります。

GeneSISはPassword、2FA Code、Backup Code、完全なCard情報等を求めません。

Privacy請求の詳細は[Privacy Notice](./PRIVACY_NOTICE.md)をご確認ください。

## 4. Security Reports

未修正Security問題はPublic Issue / SNSへ投稿しないでください。

GitHub Private Vulnerability Reportingが有効な場合はその経路を使用します。利用できない場合は公式Emailへ件名`[Security Report]`で連絡してください。

詳細：[Security Policy](../SECURITY.md)

## 5. Support Scope

GeneSISは可能な範囲で、問い合わせ確認、不具合整理、Documentation修正、Compatibility情報整理、Update検討等を行います。

ただし次を保証しません。

- 固定時間内の返信
- 全報告への個別返信
- 全問題の再現
- 全不具合の修正
- 特定Featureの実装
- 実装・提供時期
- 全Windows環境へのCompatibility
- 永続Support

Supportは24時間監視・緊急窓口・SLAではありません。

購入額、BOOST、Founder Support等は、Technical IssueやFeedbackの評価Priorityを変更しません。

## 6. Source Code / Internal Materials

Overout Source Code、内部Build、非公開Design資料等はPublic Support対象として開示しません。

## 7. Abuse / Repeated Contact

Spam、脅迫、嫌がらせ、過度な反復連絡、第三者権利侵害、Security Risk等がある場合、対応を制限・終了する場合があります。
