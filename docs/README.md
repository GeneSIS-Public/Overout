## EULAについて

Overout v1.0.0の利用条件については、正式Release Package内の日本語`EULA.txt`をAuthoritative Textとして扱います。

GitHub上の[EULA](./EULA.md)は、その正式Release Package EULAと**byte-for-byte同期したPublic Copy**です。

英語版は内容理解を補助するReference Translationです。

- [日本語 EULA](./EULA.md) — 正式Release Package内のAuthoritative EULAとbyte同期したPublic Copy
- [English EULA](./EULA_EN.md) — Reference Translation

日本語版と英語版の間に解釈上の差異がある場合は、正式Release Package内の日本語`EULA.txt`を基準とします。
