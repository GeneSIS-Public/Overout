2. 製品の位置づけ
======================================================================

OveroutはWindows上で動作するText acquisition / editing APPです。

主な機能・ConceptにはSALVAGE、PREPARATION、Shared Document Buffer、
Clipboard Text Capture、P.R.E.S.S.、C.O.D.E.C.、I.C. Move、L.A.I.N Navi、
s-CO2、S.N.A.K.E.D.等が含まれます。

S.N.A.K.E.D.（Space Normalization And Key Extraction Display）は、
PREPARATIONにおける空行の検出・可視化・正規化に関するConcept名称です。
Overout v1.0.0では、主にBlank DetectionとBlank Compressへその考え方が
反映されています。

Overout v1.0.0は、通常利用のために外部Python環境を必要としません。

Overout v1.0.0の通常機能は、外部Network Serviceへの接続を前提としません。

5. Clipboard / Local Data
======================================================================

Overoutは、SALVAGE Mode中にWindowsでTextがCopyされClipboard上のTextが更新された場合、
そのTextをShared Document Bufferへ取り込む処理を行います。

本規約および同梱READMEでは、このOverout独自の取得処理を
`Salvaging / SALVAGE取得` と呼びます。

ACTIVE / PASSIVEはSalvagingのON / OFFではなく取得方式の違いであり、
どちらの場合もSALVAGE Mode中にCopyしたTextは取り込み対象となります。

Operatorは、Clipboardへ機密情報、個人情報、第三者の秘密情報等が含まれる可能性を考慮し、
Salvagingを意図しないCopy操作を行う場合はPREPARATIONへ切り替える、Overoutを終了する等、
利用状況に応じた適切な操作を行うものとします。

設定は通常のLocal Fileとして次へ保存されます。

%LOCALAPPDATA%\Overout\config.json

Overoutは、当該Configを独自方式で保存時暗号化することを保証しません。
OperatorはWindows Account、Device、Backup先等を自ら適切に管理するものとします。
