This document defines contact routes, support scope, and the basic response policy for Overout.

## 1. Contact Routes

| Matter | Route |
|---|---|
| Short questions, reading order, basic usage | [Quick Questions](https://note.com/genesis_protocol/n/n6a2a06ad2698) |
| Publicly shareable and reproducible ordinary defects | GitHub Issues — Bug Report |
| Public Documentation errors, omissions, or unclear text | GitHub Issues — Documentation Feedback |
| Function, workflow, or UI suggestions | GitHub Issues — Development Feedback |
| Purchases / Project: Code-NOAH Phase 1 Founder Support / EULA / terms / rights | Official GeneSIS Contact |
| Personal-information handling / Privacy requests | [Privacy Notice](./PRIVACY_NOTICE_EN.md) / Official GeneSIS Contact |
| Non-public defects / individual private matters | Official GeneSIS Contact |
| Unresolved Security issues | Private route in the [Security Policy](../SECURITY_EN.md) |

**Official GeneSIS Contact**

`genesis.official.poc@mail.com`

Replies, comments, and DMs on X, YouTube, note, or other social media are not formal support channels.

## 2. GitHub Issues

For ordinary defects, include where possible: Overout Version, Windows Version, Function / Mode involved, summary, steps to reproduce, expected / actual behavior, frequency, confirmed workaround, and publicly safe logs / screenshots.

Do not post personal information, purchase or Founder information, credentials, confidential Clipboard Text, third-party secrets, private local files, or exploitable details of unresolved Security issues.

## 3. Private Inquiries

Suggested subject prefixes:

```text
[Purchase]
[Founder]
[EULA]
[Rights]
[Privacy]
[Private Bug]
[Other]
```

For Founder / purchase verification, GeneSIS may request a BOOTH order number, product name, or approximate purchase date.

GeneSIS will not request passwords, two-factor authentication codes, backup codes, private keys, or complete card/payment credentials.

See the [Privacy Notice](./PRIVACY_NOTICE_EN.md) for Privacy requests.

## 4. Security Reports

Do not post unresolved Security issues publicly.

When GitHub Private Vulnerability Reporting is enabled, use that route. Otherwise email the official GeneSIS contact with `[Security Report]`.

See the [Security Policy](../SECURITY_EN.md).

## 5. Support Scope

GeneSIS may review inquiries, organize defects, revise Documentation, collect Compatibility information, and consider Updates where reasonably possible.

No fixed reply time, response to every report, reproduction of every issue, correction of every defect, feature implementation, delivery date, compatibility with every Windows environment, or indefinite support is guaranteed.

Support is not a 24-hour monitoring service, emergency channel, or SLA.

Purchase amount, BOOST, or Founder Support status does not change technical priority.

## 6. Source Code / Internal Materials

The Overout source code, internal builds, and non-public design materials are not disclosed through public support.

## 7. Abuse / Repeated Contact

GeneSIS may limit or end handling of spam, threats, harassment, excessive repeated contact, rights violations, or conduct creating Security risk.
