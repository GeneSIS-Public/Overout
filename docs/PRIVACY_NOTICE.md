## 2. Local-first Product Data

OveroutはLocal-first Applicationです。

次のOverout Local Dataは、通常利用だけでGeneSISへ自動送信・自動収集されません。

- Windows ClipboardからSalvageしたText
- Shared Document Buffer
- SALVAGE / PREPARATIONで編集・整理した内容
- Tags / Layer Markers / Timestamps
- File Outputで生成したLocal File
- Local File Path
- `%LOCALAPPDATA%\Overout\config.json`
- その他Operator環境内のLocal Data

Overout v1.0.0は、Clipboard内容をGeneSISまたは外部Serviceへ送信するためのNetwork機能を必要としません。

## 3. Information GeneSIS May Handle

GeneSISが取り扱う情報は、PlatformからGeneSISへ実際に表示される情報、または利用者本人が自ら送信した情報を中心とします。

### 3.1 Support / Security Submissions

利用者が自ら送信した範囲で、次を扱う場合があります。

- Name / Display Name / Handle
- Email Address
- 問い合わせ本文
- 添付資料
- Overout Version
- Windows / OS / Runtime情報
- Log / Screenshot
- Reproduction Information
- 利用者が送信したConfig情報
- 対応履歴

不要な個人情報、認証情報、秘密情報、機密Clipboard Text、第三者情報は送信前に削除・伏字してください。

### 3.2 BOOTH / Purchase / Founder Support

BOOTH等を通じ、Platform上でGeneSISに表示される範囲の情報を扱う場合があります。

- BOOTH上で確認可能な購入者情報
- Order / Product / Purchase Time等の記録
- Overout購入確認に必要な情報
- G.E.N.E Founder Support資格の確認
- Overout Additional Deliverable提供に必要な情報

GeneSISはBOOTHの決済処理を直接行わず、完全なCredit Card情報等を取得することを目的としません。

### 3.3 GitHub

GitHubでは必要に応じて次を扱う場合があります。

- Public Profile
- Issues / Comments
- Documentation / Development Feedback
- Security Report
- Private Vulnerability Reportingで送信された情報
- その他利用者がGitHub上で自ら公開・送信した情報

### 3.4 Other Official Media

note、X、YouTube等における公開Activityを確認する場合があります。

SNS上のDMは正式問い合わせ経路ではありません。

### 3.5 Technical Records

Email Serviceや各Platformが、通信・Security・運用上のTechnical Recordを独自に保持する場合があります。

GeneSIS-Operatorが各Platformの保有情報すべてを取得または管理するものではありません。

## 4. Purposes of Use

取得した情報は必要な範囲で次に利用します。

- 問い合わせ確認・回答
- 不具合、Compatibility、Security問題の調査
- Documentation改善
- Release / Known Limitations / Support案内改善
- Purchase確認
- G.E.N.E Founder Support資格およびOverout Additional Deliverable提供確認
- EULA、権利、利用条件への対応
- Privacy・権利請求
- 不正利用、Spam、脅迫、嫌がらせ、Security Riskへの対応
- 法令上必要な対応
- GeneSIS / Project: Code-NOAHの開発・運営記録

## 5. AI Assistance

GeneSIS-OperatorはDocumentation、翻訳、Technical Review、問い合わせ内容の整理等を補助するためAIを利用する場合があります。

非公開情報をAIで扱う必要がある場合は、目的に必要な範囲へ削減し、必要に応じて匿名化・伏字します。

Password、認証Code、秘密鍵、完全な決済情報等を意図的にAIへ入力しません。

Purchase / Founder資格、権利、Privacy請求、Security対応その他の重要事項についてAIのみで最終判断しません。最終判断はGeneSIS-Operatorが行います。

## 6. Third-Party Services

運営上、次の第三者Serviceを利用する場合があります。

- BOOTH
- GitHub
- note
- X
- YouTube
- Email Service
- AI Service

利用者がこれらのPlatformを利用した場合、各Platform運営者もそれぞれの利用規約・Privacy Policyに基づいて情報を処理します。処理拠点が日本国外となる場合があります。

GeneSISは各Platformが保有する利用者情報全体を取得・管理・支配するものではありません。

## 7. Retention / Deletion

一律の固定保存期間は設定しません。

利用目的、対応履歴、紛争、Abuse、Security対応、Platform仕様、法令上の必要性等に応じて必要な範囲で保存します。

目的が終了し保存の必要がなくなった情報は、合理的に可能な範囲で削除または識別性を低減します。

BOOTH、GitHub、note、Xその他Platform側に保存された情報は各Platformの機能・手続に従います。

## 8. Safeguards

情報の性質と個人運営の規模を考慮し、次のような措置を行います。

- Accountごとの適切なPassword管理
- 利用可能な場合のTwo-Factor Authentication
- Access可能なAccount / Device / Connected Appの制限
- 認証情報・機微情報の不要な収集を避ける
- Public / Non-public Informationの分離
- 不要となった情報の整理・削除
- Security問題確認時の必要な対応

Internet / Third-Party Platform利用において絶対的Securityを保証するものではありません。

## 9. Access, Correction and Other Privacy Requests

適用法令上認められる範囲で、本人に関する情報の利用目的通知、開示、訂正、追加、削除、利用停止、消去、第三者提供停止等の請求を受け付けます。

**Privacy Request Contact**

`genesis.official.poc@mail.com`

推奨Subject：

```text

```

対象情報と希望する対応を可能な範囲で明示してください。

本人確認、第三者権利保護、Security、不正請求防止のため必要最小限の確認情報を求める場合があります。

法令上対応できない場合、第三者の権利利益を害するおそれがある場合、対象情報をGeneSISが保有していない場合、またはPlatform保有情報をGeneSISが削除・変更できない場合は、請求の全部または一部へ対応できないことがあります。

一般的な連絡方法は[Contact and Support](./CONTACT_AND_SUPPORT.md)をご確認ください。

## 10. Data Incident Response

個人情報の漏えい、紛失、毀損その他Incidentを確認した場合、GeneSIS-Operatorは範囲を確認し、Access制限、Credential変更、本人への通知、Platformへの報告、関係当局への報告その他必要な対応を検討します。

未修正Security問題は公開せず[Security Policy](../SECURITY.md)の非公開経路を使用してください。
